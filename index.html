Bluetooth heart-rate sensor

Pair a device that advertises the standard Bluetooth Heart Rate service. Open Aviceena in Chrome or Edge if pairing is unavailable here.

▤

Import a device export

Import a CSV formatted as timestamp,metric,value. Use ISO timestamps with a time zone and the units shown below.

heart (bpm), glucose (mg/dL), temperature (°C), sleep (hours), oxygen (%)

Your privacy

Chat stays in this tab. The journal stays in this tab unless you opt into browser storage. Saved journal data can be accessed by other people using this browser profile. Chat is processed through local Ollama. To include recent readings, select the checkbox for that message. A model reply may refer back to readings you previously shared in the same conversation.

You can clear the conversation or readings at any time. Downloaded summaries remain where you save them.
